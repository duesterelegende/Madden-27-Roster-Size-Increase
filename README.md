# Madden-27-Roster-Size-Increase
This Mod increase follow Values

Roster Size Preseason to 80
Roster Size Cutday / regular Season to 65
Player on Practice Squad to 3 Years

for better Gamebalance was needed to increase Start Salary Cap +40m

the ingame salary logic is not changed, in M27 is automatic increased and calculated the salary cap year for year. 


ATTENTION!
To use the new values you NEED to start a NEW FRANCHISE GAME. NOT possible to get the values with existing save files

Overview tables für roster is limited to 60 and hardcoded by EA in exe file. you can only see full roster overview in line up or
in depth table seperatly for each position.

the minimum roster size is hardcoded to by EA in exe file. for better Game balance you should use highest value stetting

Deutsch
Dieser Mod erhöht folgende Werte:

Kadergröße in der Vorsaison auf 80
Kadergröße am Cutday / in der regulären Saison auf 65
Spieler im Practice Squad auf 3 Jahre

Für eine bessere Spielbalance war es notwendig, die Start-Gehaltsobergrenze um +40 Mio. zu erhöhen.

Die Gehaltslogik im Spiel bleibt unverändert; in M27 wird die Gehaltsobergrenze automatisch Jahr für Jahr erhöht und neu berechnet.


ACHTUNG!
Um die neuen Werte zu nutzen, MUSST du ein NEUES FRANCHISE-SPIEL starten. Es ist NICHT möglich, die Werte mit bestehenden Speicherständen zu übernehmen.

Die Übersichtstabellen für den Kader sind auf 60 Spieler begrenzt und von EA fest in der EXE-Datei programmiert. Die vollständige Kaderübersicht kannst du nur in der Aufstellung/ Line up oder
in der detaillierten Kadertabelle separat für jede Position einsehen.

Die Mindestgröße des Kaders ist von EA fest in der EXE-Datei programmiert. Für eine bessere Spielbalance solltest du die höchste Einstellung verwenden.
